## Reporting a Vulnerability

If you discover a potential security vulnerability within the CLI, the validation judge, or believe a rule in this Knowledge Base contains inaccurate or unsafe security recommendations:

1. **Do NOT open a public GitHub issue.**
2. Please report the issue privately by contacting:
   - Email: `viahofarel@gmail.com`
   - Or open a [GitHub Private Vulnerability Report](https://github.com/Alpha2-far/engineering-kb/security/advisories/new) if enabled on the repository.

Please provide:
- A clear description of the vulnerability or inaccurate rule.
- Steps to reproduce or proof of concept.
- Authoritative documentation (RFC, CVE, NIST, OWASP) if refuting a normative rule.

We take security reports very seriously and will investigate and respond promptly.
