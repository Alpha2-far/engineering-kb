Agent-Native Security v1.0 · FastMCP Engine

KB Security Context Server

Fournisseur de contexte de sécurité temps-réel pour agents de code (Claude Code, Cursor, Codex, Antigravity) — l'équivalent direct de Context7 appliqué à la sécurité applicative. Fournit à chaud via MCP des règles normatives vérifiées (OWASP, NIST, RFC), des patterns de code sûrs (« Do / Don't ») et l'audit mécanique instantané du code généré.

Python 3.12+ Astral uv FastMCP Pydantic v2 Typer & Rich Local-First (Zero Cloud Cost)

Fonctionnalités clés (Périmètre In-Scope)

  • Serveur MCP Natif pour Agents

    Exécute un serveur stdio standardisé que tout agent IA (Claude Code, Cursor, Codex) peut invoquer en temps réel pendant la rédaction de code.

  • Patterns Do / Don't Concrets

    Associe à chaque règle un exemple de code vulnérable fréquent chez les LLMs et le code sécurisé de référence à implémenter.

  • Résolution Sémantique Économe

    Résout une intention technique ("JWT auth FastAPI", "vector search") vers un condensé strict de règles prioritaires (~1 000 tokens max).

  • Audit de Code en Mémoire

    Vérifie en quelques millisecondes un bloc de code généré pour intercepter les failles mécaniques avant qu'elles n'atteignent le fichier sur disque.

  • Ancrage Normatif Strict (>= 85%)

    Toutes les règles sont prouvées mathématiquement contre des documents officiels archivés (OWASP, NIST, RFC, CIS). Zéro hallucination.

  • Distribution Zéro-Config (uvx)

    Branchement instantané dans la configuration MCP de l'utilisateur sans build lourd ni dépendance globale requise.

Déjà fourni par le codebase existant

  • Registre de 95 sources officielles (OWASP, RFC, NIST)
  • Moteur d'ancrage textuel Grounding Judge (seuil 85%)
  • 47 règles de sécurité compilées et validées (0 rejet)
  • Audit statique CLI tri-state (matière / sans occurrence / hors-périmètre)
  • Suite de 22 tests unitaires automatisés & CI GitHub Actions

Exclusions explicites (Hors-Périmètre v1)

  • Pas de SaaS / Dashboard web / Facturation — Focus à 100 % sur l'infrastructure pour agents et développeurs.
  • Pas d'auto-fix en boîte noire — L'outil conseille et alerte avec des patterns précis sans modifier le code de façon opaque.
  • Pas de scraping web en temps réel au runtime — Seules les règles officielles archivées et vérifiées sont servies.
  • Pas d'analyse dynamique en sandbox (DAST) — Analyse statique instantanée uniquement, sans exécution arbitraire de code.
  • Zéro dépendance cloud payante obligatoire — Moteur 100 % autonome et fonctionnel en local-first.

Modèle de données

Les entités manipulées par KB pour distribuer et auditer la sécurité.

Rule (Règle enrichie)

id / title Identifiant immuable (KB-0015) et règle impérative.
do_pattern Extrait de code sécurisé recommandé à destination de l'agent.
dont_pattern Piège de code vulnérable fréquent produit par les LLMs.
frameworks Tags cibles (fastapi, supabase, docker, jwt, nextjs).
evidence Citation verbatim officielle et SHA-256 du document archivé.

Relié à · SecurityTopic

SecurityTopic (Index Sémantique)

slug Identifiant thématique (fastapi-jwt, rag-isolation, docker-root).
keywords Synonymes et termes naturels employés dans les prompts d'agents.
rule_ids Liste ordonnée des règles applicables par criticité décroissante.

Relié à · Rule

AuditVerdict (Retour Diagnostic Mémoire)

clean Booléen validant la conformité mécanique du code inspecté.
findings Liste des violations avec ligne, motif suspect, règle violée et snippet do_pattern suggéré.

Jalons de Réalisation (Milestones)

1

Fondations Schéma, Do/Don't Patterns & Recherche Sémantique

Enrichissement du schéma des règles de sécurité avec les patterns de code, indexation thématique et moteur de résolution sémantique en mémoire.

Ce qui est construit

  • Extension du schéma Pydantic (champs do_pattern, dont_pattern, frameworks).
  • Mise à niveau des règles existantes avec snippets de code sûrs et vulnérables.
  • Moteur de recherche sémantique local-first (search.py) avec scoring de pertinence.
  • Commande CLI interactive kb search <query> avec rendu Rich coloré.
  • Tests unitaires complets sur le schéma et le moteur de recherche.

Exclu de ce jalon

  • Le serveur de protocole MCP (prévu au Jalon 2).
  • L'outil d'audit de snippets en mémoire (prévu au Jalon 2).
  • La configuration externe pour clients tiers.

Critère de validation : Lancer uv run kb search "JWT auth FastAPI" affiche instantanément les règles applicables avec leurs patterns Do/Don't en console, et 100% des tests unitaires sont verts.

2

Serveur MCP Natif pour Agents & Audit à la Volée

Implémentation du serveur FastMCP exposant les 3 outils essentiels d'interrogation et d'audit pour tout agent de code.

Ce qui est construit

  • Serveur FastMCP stdio standard dans kb/src/kb/server.py.
  • Outil resolve_security_topic(query) pour mapper les intentions de l'agent.
  • Outil get_security_rules(topic, max_rules) taillé pour économiser le contexte.
  • Outil audit_code_snippet(code, filename) analysant en mémoire le code généré.
  • Commande CLI kb mcp démarrant le serveur.
  • Tests unitaires simulant des appels d'outils MCP clients.

Exclu de ce jalon

  • L'expansion massive du corpus (réservée au Jalon 3).
  • Les configurations prêtes à l'emploi multi-IDE.

Critère de validation : Le serveur démarré via uv run kb mcp traite avec succès les appels des 3 outils MCP et détecte immédiatement une faille simulée dans un snippet de test.

3

Expansion du Corpus & Packaging Zéro-Config

Enrichissement ciblé sur les angles morts des modèles d'IA, packaging universel et documentation d'onboarding pour tous les agents du marché.

Ce qui est construit

  • Packs de règles supplémentaires ancrés sur les failles LLMs récurrentes (Auth, RAG, API).
  • Validation stricte des nouvelles citations à 100% au Grounding Judge.
  • Snippets de configuration prêts à l'emploi pour Cursor, Claude Desktop, Claude Code et Antigravity.
  • Packaging final pyproject.toml permettant l'exécution directe via uvx kb mcp.
  • Test end-to-end complet avec un agent de codage réel.

Exclu de ce jalon

  • Règles non ancrées dans des sources officielles.
  • Applications web ou interfaces SaaS tierces.

Critère de validation : Un agent de code externe interroge KB via uvx kb mcp, reçoit les patterns sécurisés et passe la CI GitHub Actions avec succès.
